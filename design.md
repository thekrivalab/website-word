# Word — design brief

Status: foundation only. Visual direction is intentionally pending.

## Studio and audience

Word is a fictional contemporary architecture studio. The initial business brief
also uses the name “Atelier Norte”; Word is the working public brand until clarified.
The studio specializes in contemporary residential architecture, minimalist
interiors, and sophisticated architectural experiences for high-end private clients.

## Website goal

Present the studio’s work, communicate its philosophy, and attract prospective clients.

## Planned sections

1. Hero
2. Studio introduction
3. Selected projects
4. Design philosophy
5. Services
6. Contact

## Next design stage

- Apply the dedicated design skill when supplied.
- Review visual references and establish typography, palette, grid, and spacing.
- Create or source project imagery before implementing the final compositions.
- Develop approved studio copy, project details, and real contact information.
- Define motion only where useful; add GSAP if the approved interactions need it.

## Implementation baseline

- Astro, strict TypeScript, and Tailwind CSS through its Vite plugin.
- Responsive layouts, semantic landmarks, visible focus states, and keyboard access.
- Respect reduced-motion preferences when animation is introduced.
- Keep the placeholder page simple; it is not the final hero or site design.
- Keep future assets local when possible, supply meaningful alternative text, and
  use Astro’s image pipeline for content images.
